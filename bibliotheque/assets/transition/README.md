# Séquence de transition (emplacements)

Fichiers attendus (non fournis à ce jour — À VALIDER) :

- `book-laptop-cognitio.webm` (préféré) et `book-laptop-cognitio.mp4` (repli),
- `book-laptop-cognitio-poster.webp` (image fixe).

Scénario : les pages d'un livre s'ouvrent → un ordinateur portable en émerge → une feuille sort de l'écran → elle se plie en Cognitio → Cognitio invite dans l'univers.
Durée : 3 à 5 s. Sans ces fichiers, `src/transition.js` joue une séquence procédurale (HTML/CSS/SVG) équivalente.
Après dépôt : `python3 tools/build-data.py` détecte les fichiers et active la vidéo.
